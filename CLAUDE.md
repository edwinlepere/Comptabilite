## Approche
- Lire les fichiers existants avant d'ecrire. Ne pas relire sauf si modifie.
- Raisonnement approfondi, reponses concises.
- Ignorer les fichiers de plus de 100 Ko sauf necessite explicite.
- Pas d'ouverture complaisante ni de conclusion inutile.
- Pas d'emojis.
- Ne pas deviner les API, versions, flags, SHA de commits ou noms de packages. Verifier dans le code ou la doc avant d'affirmer.
